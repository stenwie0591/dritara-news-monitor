# Micro-task template

```markdown
### MXX.YY — Titolo

- Parent: MXX
- Stato: proposed | ready | in_progress | in_review | done | blocked | cancelled | superseded
- Owner/agent: unassigned
- Outcome: effetto osservabile
- Scope / non-scope: ...
- Dipendenze: ID o nessuna
- Rischio: low | medium | high — motivazione
- Acceptance criteria: condizioni Given/When/Then o metriche
- Verifica: test, benchmark, review, drill
- Rollout/rollback: piano o N/A motivato
- Documenti impattati: percorsi
- Evidenze: link a test/report/PR; `pending` finché non concluso
- DoD specifica: condizione misurabile propria del task
```

Si applica anche la [DoD globale](definition-of-done.md). Un task non diventa `done` sostituendo evidenze mancanti con una dichiarazione generica.
