# Macro gate reviews

Questa cartella contiene i record evidence-based prodotti alla chiusura dei macro-task. Usare `docs/governance/macro-review-template.md` e il nome `MXX-YYYY-MM-DD.md`.

Un file può nascere con decisione `PENDING`; `GO`, `RECYCLE`, `HOLD` o `STOP` richiedono approvatore umano e data. Nessun agente AI può auto-approvare un gate.
